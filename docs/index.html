Reel: Video understanding for AI agents

Give a language model a film. Reel supplies timestamped pictures and audio evidence through the Model Context Protocol (MCP). An agent can advance through a video, inspect the original pixels of a frame, and replay an interval it has already seen.

Reel runs on Apple Silicon Macs with Python 3.11 or later and FFmpeg. The software is open source under the MIT license.

View the source code and demo on GitHub

What you can do

  • Install a video MCP server for Codex and other AI agents.
  • Inspect frozen frames, repeated sounds, and subtitle timing.
  • Read measured video and audio understanding results.

One picture, two recordings

In the door experiment, the same 204 frames were paired with two recordings. With local audio-model descriptions, GPT mentioned a short rattle in one and an unidentified faint sound in the other. Watch the 18-second comparison and read the actual responses.

Reel presents evidence rather than deciding what makes a good edit. Sound sources and words can still be missed.
