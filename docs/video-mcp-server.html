Video MCP server for AI agents

Reel exposes a local film in chronological order so an agent can inspect frames, sound measurements and previously released intervals.

Install on macOS

Install FFmpeg (brew install ffmpeg) and Python 3.11 or later on an Apple Silicon Mac, then install Reel from PyPI.

pipx install reel-mcp

Analyze video with Claude Code or Codex

Substitute your actual video path for film.mp4 and register the server:

claude mcp add reel -- reel-mcp "$PWD/film.mp4" --until 8.5 --image-client
codex mcp add reel -- reel-mcp "$PWD/film.mp4" --until 8.5 --image-client

Open a new chat and ask the agent to watch the film, report timestamps and replay any unclear moment. Adjust the cutoff or omit it to watch a longer interval.

Frames, audio and replay

The view tool advances the film, look inspects original pixels, and observe pairs frames and recorded sound. Image-and-text clients receive frames and acoustic measurements; optional local readers add sound descriptions and speech. Audio-capable clients can also receive original-channel WAV audio. A replay cannot reveal unreleased portions of the film.
